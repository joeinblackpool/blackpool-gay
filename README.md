# Blackpool.gay

One-page LGBTQ+ guide to Blackpool, served by the Cloudflare Worker `blackpool-gay`.

This repo was empty; the code here is the live Worker as of 20 Oct 2026, saved from Cloudflare. The page HTML is in `src/index.html` and `src/404.html`; `src/worker.js` serves them.

Deploy: `npx wrangler deploy`.
